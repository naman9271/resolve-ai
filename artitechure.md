## System Design

### Website Architecture
- Frontend: Nextjs (-> Anvay)

- Backend: Python FastAPI (-> Daksh)
- Database: PostgreSQL/SQLite
- Room: WebSocket (Socket.io)
- Authentication: OAuth 2.0 (Google)
- Resource Hub Storage: Supabase S3

- LLM - Qwen 2.5 + RAG (-> Naman)
- OCR - Tesseract (python)
- Vector Database: Pinecone/Weaviate
- AI Agent - Emotional Support Chatbot (n8n/langgraph)

### WhatsApp Bot Architecture
- Messaging Service: Twilio or WhatsApp Business API
